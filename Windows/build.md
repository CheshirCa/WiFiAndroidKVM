# Сборка Windows-клиента

Исходник `WiFiAndroidKVM.pb` сохранён в UTF-8 с BOM. Это необходимо PureBasic для корректного чтения русских строк интерфейса.

Используйте PureBasic 6.41 x64. Ключ `/THREAD` обязателен: ввод и сетевой поток обмениваются очередью под mutex. Перед заменой EXE завершите предыдущий экземпляр через «Выйти» в меню трея: крестик окна теперь только скрывает его. Соберите из корня проекта через временный каталог:

```powershell
$buildDir = Join-Path $env:TEMP 'wifi_android_kvm_pb_build'
New-Item -ItemType Directory -Force -Path $buildDir | Out-Null
Copy-Item .\Windows\WiFiAndroidKVM.pb (Join-Path $buildDir 'WiFiAndroidKVM.pb') -Force
Copy-Item .\Windows\WiFiAndroidKVM.ico (Join-Path $buildDir 'WiFiAndroidKVM.ico') -Force
& 'C:\Program Files\PureBasic\Compilers\pbcompiler.exe' `
  (Join-Path $buildDir 'WiFiAndroidKVM.pb') /THREAD /EXE (Join-Path $buildDir 'WiFiAndroidKVM.exe') /ICON (Join-Path $buildDir 'WiFiAndroidKVM.ico')
if ($LASTEXITCODE -ne 0) { throw 'Ошибка компиляции PureBasic' }
Copy-Item (Join-Path $buildDir 'WiFiAndroidKVM.exe') .\Windows\WiFiAndroidKVM.exe -Force
```

Перед запуском Windows-клиента Android Agent должен быть запущен в режиме `--server`. При старте клиент ищет устройства через UDP Broadcast `5557`; повторный поиск доступен кнопкой «Найти устройства». Двойной щелчок по результату переносит его IP и TCP-порт в поля ручного подключения. Если Broadcast недоступен, введите IP-адрес или DNS-имя и TCP-порт `5556` вручную. Последнее успешное соединение сохраняется в `WiFiAndroidKVM.ini` рядом с EXE. ADB-туннель для работы клиента не нужен.

По умолчанию включён флажок «Автопереподключение». После потери TCP клиент сразу возвращает мышь Windows и через две секунды пытается подключиться к последнему успешному IP/DNS и порту. Discovery в фоне не выполняется. Ручное выключение удалённого управления или отключение флажка отменяет отложенную попытку.

В удалённом режиме курсор Windows фиксируется в одной точке через `ClipCursor`, движения считываются через Raw Input. Кнопки и колесо обрабатывает короткий глобальный hook; он только ставит события в очередь. Все TCP-пакеты передаёт один поток, без обращения к интерфейсу. Для коротких пакетов отключён Nagle; тайм-аут отправки — 1 секунда. При выключении, потере соединения или выходе ограничение курсора снимается.

Ручное подключение выполняется в отдельном потоке, поэтому недоступный планшет не блокирует окно и глобальные hooks. При выключении управления очередь сначала получает key-up для всех зажатых клавиш, затем sender отправляет их до DISCONNECT. Неотображаемые клавиши, XButton и горизонтальное колесо не передаются, но также не попадают в Windows во время удалённого режима.

В этом режиме перехватывается и клавиатура: поддерживаются основной буквенно-цифровой ряд, пробел, Enter, Escape, Tab, Backspace, Delete, Delete на дополнительной цифровой клавиатуре, модификаторы и навигационные клавиши. `Ctrl+Alt+M` остаётся локальной комбинацией возврата в Windows и на Android не передаётся; она распознаётся по физической клавише M и не зависит от раскладки. Повторные `keydown` от Windows не передаются до `keyup`, поэтому одно короткое нажатие создаёт один символ. Агент освобождает все нажатые клавиши при разрыве TCP.

При возврате по `Ctrl+Alt+M` клиент подавляет завершающие отпускания Ctrl, Alt и M, потому что их нажатия уже были перехвачены. Одновременно он явно снимает в Windows состояния Shift, Ctrl и Alt. Это не даёт Windows сохранить модификатор после выхода из удалённого режима.

## Проверка мыши

1. В обычном режиме кнопка интерфейса должна нажиматься.
2. После `Ctrl+Alt+M` курсор Windows должен оставаться на месте, а курсор Android — двигаться непрерывно, в том числе при длительном движении в одном направлении.
3. Проверьте левую, правую, среднюю кнопки и колесо на Android.
4. Наберите несколько букв, цифр, пробел, Enter и стрелки в поле ввода на Android. Удерживайте и отпускайте Shift, Ctrl и Alt.
5. Повторное `Ctrl+Alt+M` должно вернуть управление Windows. Эта комбинация не должна появиться на Android. Повторите переключение несколько раз.
6. При разрыве соединения клиент должен вернуть управление Windows и освободить клавиши на Android.

При рывках остановите мышь и запишите значения «Raw Input» и «Пакеты движения», затем подвигайте её несколько секунд и снова запишите значения. Первый счётчик показывает число ненулевых относительных событий, второй — число переданных пакетов движения. Из-за объединения смещений числа обычно различаются. Также укажите, оставался ли курсор Windows неподвижным, было ли окно клиента активным, и работали ли кнопки.

Мышь, клавиатура, `Ctrl+Alt+M`, Backspace и ранее проблемные буквенные клавиши подтверждены пользователем на физическом планшете.

Если счётчики растут, но движение идёт рывками, выполните отдельный [тест транспорта](../docs/mouse_diagnostics.md), чтобы измерить паузы на приёме без виртуального ввода.

## Wi-Fi KeepAlive

В клиенте доступен прикладной KeepAlive: флажок включён по умолчанию, поле справа задаёт интервал в миллисекундах (10–1000, начальное значение 50). Пакеты PING передаются только при активном удалённом управлении по существующему TCP-соединению; отключите флажок для сравнения плавности.

Флажок и интервал теперь сохраняются в INI. Пользователь подтвердил нормальную работу при 700 мс; существующее значение не заменяется при обновлении клиента.

## Язык, тихий запуск и автозапуск

Английский интерфейс встроен в `WiFiAndroidKVM.exe` и применяется по умолчанию. Рядом с EXE должен находиться единый файл `WiFiAndroidKVM.lng` в UTF-8: он содержит секции языков, например `[ru]`, с отображаемым именем `Name=Русский` и строками `Key=Value`. При запуске клиент читает все секции и предлагает их в окне и отдельном подменю языка в трее; пустые и отсутствующие значения строк используют встроенный английский текст. Код секции сохраняется в `WiFiAndroidKVM.ini`, секция `[Options]`, ключ `Language`; новых языков можно добавить сколько угодно.

Язык выбирается выпадающим списком в окне или двумя пунктами трей-меню. Изменение вступает в силу немедленно; русский файл не нужен для выбора английского.

Запустите клиент скрытым в трей:

```powershell
.\Windows\WiFiAndroidKVM.exe /silent
# или
.\Windows\WiFiAndroidKVM.exe /s
```

Флажок «Запускать вместе с Windows» создаёт для текущего пользователя строку `WiFiAndroidKVM` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. Значение содержит полный путь к EXE и `/silent`, поэтому при входе в Windows окно не появляется. Права администратора не требуются. Снимите этот же флажок, чтобы удалить запись.

При успешном включении управления появляется предупреждение в верхней части основного монитора поверх обычных окон: «Мышь и клавиатура перехвачены» и «Вернуть управление Windows: Ctrl+Alt+M». Оно остаётся видимым всё время управления, даже если основное окно скрыто в трей, не требует нажатия OK и не меняет активное окно. При возврате управления, потере соединения или выходе предупреждение исчезает. После успешного автопереподключения оно появляется снова.

Значок создаётся при запуске: синий означает управление Windows, зелёный — планшетом. Меню трея содержит «Показать/Скрыть окно», «Включить/Выключить удалённое управление» и «Выйти». Во время ожидания восстановления соединения доступна команда «Отменить переподключение». Двойной щелчок по значку показывает окно. Крестик и кнопка «Скрыть в трей» скрывают окно, сохраняя горячую клавишу и сетевую обработку. Если создание значка не удалось, окно нельзя скрыть, а крестик завершает приложение.

В удалённом режиме мышь Windows зафиксирована, а кнопки перехватываются для Android. Нажмите `Ctrl+Alt+M`, чтобы вернуть управление Windows, затем откройте трей или настройки. Для завершения приложения используйте «Выйти»: курсор освобождается, отправляется существующий DISCONNECT, hooks снимаются и фоновые потоки завершаются.

Ползунок «Чувствительность мыши» задаёт 25–300%. Значение 100% соответствует прежним относительным смещениям; кнопка «100%» восстанавливает его. Масштабируется только движение Android, кнопки, колесо и клавиатура не меняются. Дробные смещения накапливаются отдельно по двум осям, а большие движения разбиваются на существующие MOVE-пакеты с int16. Остатки сбрасываются при смене чувствительности и переключении управления. Переход через край экрана отсутствует.

INI рядом с EXE сохраняет последнюю успешную пару Host/Port в `[Connection]`, `MouseSensitivityPercent` в `[Input]` и `KeepAliveEnabled`, `KeepAliveInterval`, `AutoReconnectEnabled` в `[Options]`. Настройки сохраняются при изменении, успешном подключении и выходе; отсутствующее или недопустимое значение чувствительности заменяется на 100%.

Проверено в Windows: запуск и отзывчивость, скрытие крестиком, восстановление командой меню, изменение 175% и сброс 100%, загрузка настроек при следующем запуске, включение/выключение управления и выход командами меню. На локальном TCP-сервере проверены исходный AUTH, PING и DISCONNECT, возврат ограничения курсора. Отдельно проверены расчёты 25–300%, знаки, дробные остатки, смена направления и разбиение больших MOVE. Физические щелчки по значку и удобство чувствительности на планшете требуют ручной проверки; APK и агент не пересобирались.
